# GX404 个人导航

参照 io724.com 的黑色背景、中央大标题与底部入口布局，独立实现 GX404 的静态门户。页面不依赖第三方字体、图片、分析服务或运行时软件包。

## 内容

- 摄影作品：https://ph.gx404.cn/
- 会员看板：https://vip.gx404.cn/
- 服务器探针：https://vps.gx404.cn/
- 文件互传：https://ios.gx404.cn/

Sub 是下载转发服务，不展示为独立页面。摄影新域名由用户指定为 `ph.gx404.cn`。

## 维护与预览

修改 `dist/site.config.js` 可以更新标题、介绍和站点入口。`dist/index.html` 保留了无 JavaScript 时可使用的静态入口，修改链接时也应同步更新该文件。

运行 `node preview.mjs`，然后打开终端给出的本地地址。发布静态文件时上传 `dist` 中的全部文件即可，不需要构建或数据库。

## 已验证

- 1280 × 720 桌面、390 × 844 手机、320 × 640 窄屏布局。
- 导航目标与独立新标签页设置。
- 动效暂停、恢复与刷新后设置保留。
- 页面无控制台警告或错误；主脚本语法检查通过。
- VIP、VPS、文件互传的公开首页返回 HTTP 200。

## 主域名切换前的准备

本目录的 Sites 预览与现有生产域名相互独立。正式将 `gx404.cn` 切换为导航，需要先让 `ph.gx404.cn` 解析到当前摄影服务所在服务器，并为该域名配置摄影服务和 HTTPS。

摄影服务继续使用现有应用与数据，不通过重新初始化数据库迁移。切换前核对真实运行版本、网站基础 URL、图片地址及登录跳转，并保存反向代理配置备份。原主域名中的作品详情链接需要对应跳转至新的摄影域名。
